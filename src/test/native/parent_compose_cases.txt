# Where a parented child ends up -- the golden table, and the ONE record of it.
#
# Parenting composes childToWorld = parentToWorld * childToParent, with the
# offset measured ONCE at link time:
#
#   link      childToParent = MatrixInvert( AngleMatrix(pAng, pOrg) )
#                             * AngleMatrix(cAng, cOrg)
#   compose   childToWorld  = AngleMatrix(nAng, nOrg) * childToParent
#             out = ( translation of that, MatrixAngles of that )
#
# That arithmetic used to be C++ -- ComputeChildToParentFrame and ComposeOneLink
# in shell_standalone_hierarchy.cpp, over mathlib's matrix3x4_t -- and is now C#.
# This file is what stops the port from quietly meaning something else. TWO tests
# read it:
#
#   sourcesharp/test/parent_compose_test.cpp   -- recomputes every row with the
#       REAL AngleMatrix/MatrixInvert/ConcatTransforms/MatrixAngles and asserts the
#       table still describes them. That is what keeps the table a record of native
#       rather than a record of a guess.
#
#   SourceSharp.Tests/HierarchyTests.cs       -- recomputes every row with
#       Hierarchy.MeasureOffset and Hierarchy.Compose, which is the port.
#
# THE ROTATIONS ARE THE POINT. `translation-only` is in the table deliberately and
# is the row a composition that ignored the parent's rotation entirely would still
# pass; every other row fails such a composition. A table of translations would be
# a check that cannot fail.
#

#   name
#   parentOrigin(3) parentAngles(3)     the parent's frame at link time
#   childOrigin(3)  childAngles(3)      where the child stood, in the world
#   movedOrigin(3)  movedAngles(3)      the parent's frame after it moved
#   outOrigin(3)    outAngles(3)        where the child is composed to
#
