# needs-cache.md — CBoneCache-cluster divergences and rulings

(`src/shared/managed/Bones/BoneCacheStore.cs`: `BoneCacheParams`,

`src/shared/native/bone_setup.cpp` (relocated stock, 6212 lines) and the
