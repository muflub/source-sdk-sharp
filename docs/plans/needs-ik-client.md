# needs-ik-client.md — ik-client-cluster divergences and promotions

Ledger for the client cluster of the `bone_setup.cpp` managed port:
`src/shared/managed/Bones/CikContext.cs`'s CIKTarget member block and the
client member rows (UpdateTargets, AutoIKRelease, SolveDependencies,
AddAllLocks, SolveAllLocks and their SolveLockParams core). One row per cited
entry id; the code comments in that file name these ids where they apply.
Stock citations are `src/shared/native/bone_setup.cpp` (relocated stock) by
the oracle ranges the port's doc-comments quote, and the fork's pristine
`src/public/bone_setup.h` / `src/mathlib/*`.

Style follows docs/plans/needs-blend.md and docs/plans/needs-ik.md: id,
citing site, finding, stock citation, ruling.

## Notes

- The `MathF.Min(est.latched, rule.latched)` in the blend arm and the
  `est.latched == 1.0` equality gates are stock quirks (its `Lerp` line for
  latched is itself commented out in the stock source), NOT managed
  inventions — pinned by UpdateTargets_TwoHalfWeightRules_BlendArmAndLatchedMinQuirk
  and UpdateTargets_FullLatch_FreezeAndDeltaTracking.
- The `d < 0.707f` twist gate is stock's `cos(45)` FIXME ("make property of
  chain") — kept as the literal, with the stock comment.
- The too-far gate `(d4 < |d1-d2| || d4*0.95 > d1+d2) && est.latched > 0.2`
  stamps `ErrorFlTime` (the dt AutoIKRelease later reads); stock's `d4` uses
  the latched delta from the PREVIOUS frame — pinned by
  UpdateTargets_TooFarLatch_StampsErrorFlTime and the two-call debounce fact
  UpdateTargets_DeltaAccumulatesAcrossTwoCalls.
