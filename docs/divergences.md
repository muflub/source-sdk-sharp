# Divergences

Where a managed port deliberately does not do what the stock C++ does, and
why. This file is the index: the code owns the detailed note, each row here
names the stock source (file:line at the pristine upstream clone the oracle
reads) and points at the port's own comment. A row with no pointer is a
divergence nobody explained.
